# Sales Data Analysis Project

## Objective
Analyze business performance using Superstore Sales Dataset.

## Tasks Performed
- Monthly Revenue Trends
- Top Selling Products
- Category-wise Sales Analysis
- Region-wise Sales Analysis
- Business Insights Report

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Insights
- Identified highest sales months
- Found top-selling products
- Analyzed category-wise sales
- Compared regional performance

## Dataset
Superstore Sales Dataset
